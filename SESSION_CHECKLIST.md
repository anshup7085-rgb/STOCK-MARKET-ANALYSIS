# Session Checklist

Before each analysis:

- [ ] Confirm current date/time.
- [ ] Confirm market and exchange.
- [ ] Confirm market open/closed status.
- [ ] Obtain current or clearly timestamped market data.
- [ ] Check broad-market regime.
- [ ] Check sector leadership/weakness.
- [ ] Scan catalysts/news.
- [ ] Screen for liquidity.
- [ ] Analyze candidates.
- [ ] Calculate risk/reward.
- [ ] Stress-test the top ideas.
- [ ] Rank opportunities.
- [ ] Check portfolio-level concentration if account data is available.
- [ ] State data limitations.
- [ ] Do not force a trade.

For live execution:
- [ ] Confirm broker/API connection.
- [ ] Confirm available permissions.
- [ ] Verify instrument and quantity.
- [ ] Verify order type.
- [ ] Verify maximum loss.
- [ ] Verify stop/invalidation.
- [ ] Obtain required user authorization.
- [ ] Confirm broker acknowledgement after submission.
- [ ] Log the result.
