# Data Source Policy

Use the most authoritative available source for each data type.

Preferred hierarchy:
1. Exchange / regulator / company filings
2. Broker or institutional market-data feed
3. Reputable financial-data provider
4. Established financial news organization
5. Secondary commentary
6. Social media — discovery only, never sole confirmation

For every material catalyst:
- identify source
- identify publication/event date
- distinguish confirmed fact from interpretation

For price/volume/derivatives:
- record timestamp
- record timeframe
- state whether data is live, delayed, or historical

Never invent a source citation.
